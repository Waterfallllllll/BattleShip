# BattleShip

Браузерная игра «Морской бой». Игрок стреляет по полю 7×7 и пытается потопить три корабля, которые расставляются случайно при каждом запуске.

## Как играть

На поле три корабля по три клетки. Корабли стоят горизонтально или вертикально и не пересекаются.

Введите координату в формате буква и цифра, например `A0`, и нажмите **Fire!** (или Enter). Строки обозначены буквами от `A` до `G`, столбцы — цифрами от `0` до `6`.

- Попадание отмечается на клетке, в сообщении появляется `HIT!`.
- Промах отмечается отдельно, в сообщении появляется `You missed`.
- Когда все три клетки корабля поражены, появляется сообщение `You sank my battleship!`.
- Когда потоплены все корабли, игра показывает, за сколько выстрелов это удалось, и поле ввода исчезает.

## Стек

- HTML и SCSS
- JavaScript без фреймворков: логика разделена на модель, представление и контроллер
- Gulp: сборка в `dist`, минификация HTML и CSS, BrowserSync для локальной разработки

## Запуск

```bash
npm install
npx gulp
```

Gulp соберёт проект в папку `dist` и откроет игру в браузере. Изменения в `src` подхватываются автоматически.
